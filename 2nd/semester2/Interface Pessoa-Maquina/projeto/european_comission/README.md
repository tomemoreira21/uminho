## 📖 About the Project

This project is a recreation of the **European Commission website**, developed using **Vue.js** and **JavaScript**.

The application retrieves information from a database through **HTTP requests** and dynamically presents the data on the website.

## ✨ Features

* 🌐 Interactive web interface
* 📡 Retrieve data through HTTP requests
* 🗄️ Database-backed content
* 🧩 Dynamic data presentation using Vue.js
* 📱 Responsive web interface

## ⚙️ Installation

### Prerequisites

* [Node.js](https://nodejs.org/) installed

### Setup

```bash
# Enter the project directory
cd european_comission

# Install dependencies
npm install
```

## 🚀 Running the Project

Start the development server:

```bash
npm run dev
```

Build the database:

```bash
npm run build:db
```

Start the JSON Server API:

```bash
npm run api
```

The frontend and API should be running at the same time in separate terminals.

After starting the development server, open the **localhost address shown in the terminal** in your browser.
