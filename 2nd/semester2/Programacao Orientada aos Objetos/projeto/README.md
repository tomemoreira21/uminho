## 📖 About the Project

**Domus Control** is a text-based smart home management system that allows users to manage houses, rooms and connected devices.

The system supports device control, automations, schedules and scenarios, providing a simple way to simulate and manage a smart home environment.

## ✨ Features

* 🏠 Manage multiple houses and users
* 🚪 Organize devices by rooms
* 💡 Control different types of smart devices
* 🤖 Create automations based on conditions
* ⏰ Schedule device actions
* 🎬 Create and execute scenarios
* 📊 Analyze device usage and energy consumption
* 💾 Save and load application state
* 🕐 Simulate the passage of time

## ⚙️ Build & Run

The project uses **Gradle**.

### Build

```bash
./gradlew build
```

### Run

```bash
./gradlew run --console=plain
```

On Windows:

```bash
gradlew.bat run --console=plain
```
